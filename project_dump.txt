# Hnefatal

**Version:** 0.3.0
**Language:** C (C11)  
**Type:** Console-based strategy board game

## Overview

Hnefatal is a turn-based strategy game inspired by the historical Nordic board game [Hnefatafl](https://en.wikipedia.org/wiki/Tafl_games).

The game is played on an 11×11 board between two opposing parties:

- **Attackers (A):** Attempt to capture the opposing king.
- **Defenders (D):** Protect the king and help him escape.

The project is developed in C, with an emphasis on modular architecture, structured data, rule validation and board-state management.

This project is currently under development.

## Game Structure

### Board

- 11 rows × 11 columns.
- Columns are labelled A–K.
- Rows are labelled 1–11.
- Each cell has a position, a type and a piece.
- Three cell types:
  - `Open`: Regular playable cell.
  - `Edge`: Board perimeter.
  - `Castle`: Central starting position.

### Pieces

| Piece | Party | Symbol |
|---|---|---|
| Attacking pawn | Attackers | `a` |
| Defending pawn | Defenders | `d` |
| King | Defenders | `k` |

Each piece also has a unique identifier.

## Movement Rules

Pieces move horizontally or vertically, like rooks in chess.

A valid move must satisfy the following conditions:

1. The destination must be on the same row or column as the starting position.
2. The destination must be empty.
3. The path between the two positions must be clear.
4. Pieces cannot traverse the central castle.
5. Only the king can occupy the castle.
6. Players can only move pieces belonging to their party.

## Board Position Notation

The board supports a compressed, FEN-like string representation.

- `a`: Attacking pawn.
- `d`: Defending pawn.
- `k`: King.
- Numbers: Consecutive empty cells.
- `/`: Separates rows.

Example:

```text
3aaaaa3/5a5/11/a4d4a/a3ddd3a/aa1ddkdd1aa/a3ddd3a/a4d4a/11/5a5/3aaaaa3
```

The notation allows board positions to be loaded from strings and converted back into strings for storage or testing.

#include "board.h"
#include <stdio.h>

static const char* START_POSITION = "3aaaaa3/5a5/11/a4d4a/a3ddd3a/aa1ddkdd1aa/a3ddd3a/a4d4a/11/5a5/3aaaaa3";

Board board_make(void)
{
    Board board = { 0 };
    int i = 0;

    for (Row row = 0; row < ROW_COUNT; row++) {
        for (Column column = 0; column < COLUMN_COUNT; column++) {
            board.cells[i].row = row;
            board.cells[i].column = column;

            if (row == ROW_1 || row == ROW_11 || column == COLUMN_A || column == COLUMN_K) {
                board.cells[i].type = Edge;
            }
            else if (row == ROW_6 && column == COLUMN_F) {
                board.cells[i].type = Castle;
            }
            else {
                board.cells[i].type = Open;
            }

            board.cells[i].piece.party = PARTY_NONE;
            board.cells[i].piece.rank = RANK_NONE;
            board.cells[i].piece.id = 0;
            i++;
        }
    }

    return board;
}

bool board_position_from_string(Board* board, const char* position)
{
    if (board == NULL || position == NULL)
        return false;

    Board parsed = board_make();
    int row = 0;
    int column = 0;
    int a_piece_id = 1;
    int d_piece_id = 1;
    int king_count = 0;

    for (int i = 0; position[i] != '\0'; i++) {
        char symbol = position[i];

        if (symbol >= '0' && symbol <= '9') {
            int empty_count = 0;

            while (position[i] >= '0' && position[i] <= '9') {
                empty_count = empty_count * 10 + position[i] - '0';
                i++;
            }
            i--;

            if (empty_count == 0 || column + empty_count > COLUMN_COUNT)
                return false;

            column += empty_count;
            continue;
        }

        if (symbol == '/') {
            if (column != COLUMN_COUNT || row >= ROW_COUNT - 1)
                return false;

            row++;
            column = 0;
            continue;
        }

        if (column >= COLUMN_COUNT || row >= ROW_COUNT)
            return false;

        Cell* cell = &parsed.cells[
            (ROW_COUNT - 1 - row) * COLUMN_COUNT + column
        ];

        switch (symbol) {
        case 'a':
            if (cell->type == Castle)
                return false;

            cell->piece = (Piece){ PARTY_A, RANK_P, 100 + a_piece_id++ };
            break;

        case 'd':
            if (cell->type == Castle)
                return false;

            cell->piece = (Piece){ PARTY_D, RANK_P, 200 + d_piece_id++ };
            break;

        case 'k':
            if (king_count >= 1)
                return false;

            cell->piece = (Piece){ PARTY_D, RANK_K, 200 };
            king_count++;
            break;

        default:
            return false;
        }

        column++;
    }

    if (row != ROW_COUNT - 1 || column != COLUMN_COUNT)
        return false;

    *board = parsed;
    return true;
}

/* AI-assisted: Converts a board into a compressed FEN-like position string. */
bool board_position_to_string(const Board* board, char position[POSITION_STRING_SIZE])
{
    if (board == NULL || position == NULL)
        return false;

    int index = 0;
    int king_count = 0;

    for (int row = ROW_COUNT - 1; row >= 0; row--) {
        int empty_count = 0;

        for (int column = 0; column < COLUMN_COUNT; column++) {
            const Cell* cell = &board->cells[
                row * COLUMN_COUNT + column
            ];

            if (cell->piece.party == PARTY_NONE) {
                if (cell->piece.rank != RANK_NONE)
                    return false;

                empty_count++;
                continue;
            }

            if (empty_count > 0) {
                int written = snprintf(
                    position + index,
                    POSITION_STRING_SIZE - index,
                    "%d",
                    empty_count
                );

                if (written < 0 || written >= POSITION_STRING_SIZE - index)
                    return false;

                index += written;
                empty_count = 0;
            }

            Piece piece = cell->piece;

            if (cell->type == Castle &&
                !(cell->piece.party == PARTY_D && cell->piece.rank == RANK_K))
                return false;

            if (index >= POSITION_STRING_SIZE - 1)
                return false;

            if (piece.party == PARTY_A && piece.rank == RANK_P) {
                position[index++] = 'a';
            }
            else if (piece.party == PARTY_D && piece.rank == RANK_P) {
                position[index++] = 'd';
            }
            else if (piece.party == PARTY_D && piece.rank == RANK_K) {
                position[index++] = 'k';
                king_count++;
            }
            else {
                return false;
            }
        }

        if (empty_count > 0) {
            int written = snprintf(
                position + index,
                POSITION_STRING_SIZE - index,
                "%d",
                empty_count
            );

            if (written < 0 || written >= POSITION_STRING_SIZE - index)
                return false;

            index += written;
        }

        if (row > 0) {
            if (index >= POSITION_STRING_SIZE - 1)
                return false;

            position[index++] = '/';
        }
    }

    position[index] = '\0';
    return king_count <= 1;
}

bool board_setup(Board* board)
{
    if (board == NULL)
        return false;

    return board_position_from_string(board, START_POSITION);
}

bool board_init(Board* board)
{
    if (board == NULL)
        return false;

    *board = board_make();

    return board_setup(board);
}

/*
 * rules.c - drop-in replacement for your rules.c.
 * Move check with error codes, captures, apply_move, is_game_over.
 *
 * COORDINATES
 *   A Position holds what the player typed: column 'A'-'K', row 1-11.
 *   Inside this file every function works with 0-based integers
 *   (row 0-10, column 0-10). The conversion is done once, in row_of()
 *   and col_of(), and only there.
 *
 * RULES IMPLEMENTED (see section 6 of the report)
 *   - Sandwich: the mover captures an enemy piece (never the king) held
 *     in a straight line between the moved piece and a friendly piece,
 *     or between the moved piece and the EMPTY castle.
 *   - Encirclement: the mover captures an enemy group (2+ pieces, connected
 *     orthogonally) when none of its pieces can move. A group that touches
 *     the board edge, or contains the king, is never captured this way.
 *   - King: captured when attackers occupy all four adjacent squares.
 *   - Encirclement is applied before sandwiches. Only the mover captures.
 *   - Board edges are never hostile.
 */
#include <stddef.h>
#include "rules.h"

#define DIRECTION_COUNT 4

  /* The four orthogonal steps: { row step, column step }. */
static const int DIRECTIONS[DIRECTION_COUNT][2] = {
    { 1, 0 }, { -1, 0 }, { 0, 1 }, { 0, -1 }
};

/* All the pieces of one side that touch each other. */
typedef struct {
    int cells[BOARD_SIZE];  /* board indexes of the pieces in the group */
    int size;
    bool touches_edge;      /* one piece is on an Edge cell             */
    bool can_move;          /* at least one piece has a legal move      */
} Group;


/* ================== small helpers ================== */

/* Convert to int first, then do ALL arithmetic on ints. Row and Column are
 * unsigned in gcc, so a difference computed on them (to->row - from->row)
 * wraps around to a huge number instead of becoming negative. */
static int row_of(const Position* pos) { return pos->row - 1; }
static int col_of(const Position* pos) { return pos->column - 'A'; }

static bool in_bounds(int row, int col)
{
    return row >= 0 && row < ROW_COUNT && col >= 0 && col < COLUMN_COUNT;
}

static int cell_index(int row, int col)
{
    return row * COLUMN_COUNT + col;
}

static Party opponent_of(Party party)
{
    return (party == PARTY_A) ? PARTY_D : PARTY_A;
}

/* -1, 0 or +1 depending on the sign of value. */
static int sign(int value)
{
    if (value > 0) {
        return 1;
    }
    if (value < 0) {
        return -1;
    }
    return 0;
}

static void remove_piece(Cell* cell)
{
    cell->piece.party = PARTY_NONE;
    cell->piece.rank = RANK_NONE;
    cell->piece.id = 0;
}


/* ================== move check ================== */

const char* move_error_message(MoveResult result)
{
    switch (result) {
    case MOVE_OK:                     return "Move accepted.";
    case MOVE_ERR_BAD_ARGUMENT:       return "Internal error: missing argument.";
    case MOVE_ERR_OUT_OF_BOARD:       return "That square is outside the board.";
    case MOVE_ERR_NO_PIECE:           return "There is no piece on the start square.";
    case MOVE_ERR_NOT_YOUR_PIECE:     return "That piece is not yours.";
    case MOVE_ERR_SAME_SQUARE:        return "The piece must move to another square.";
    case MOVE_ERR_NOT_STRAIGHT:       return "Pieces move along a row or a column only.";
    case MOVE_ERR_DESTINATION_OCCUPIED: return "The destination is occupied.";
    case MOVE_ERR_CASTLE_RESERVED:    return "Only the king may stop on the castle.";
    case MOVE_ERR_PATH_BLOCKED:       return "A piece or the castle is in the way.";
    }
    return "Unknown error.";
}

/* The real check, on 0-based coordinates. Also used by the capture code. */
static MoveResult check_move_rc(const Board* board, int from_row, int from_col,
    int to_row, int to_col, Party player)
{
    if (!in_bounds(from_row, from_col) || !in_bounds(to_row, to_col)) {
        return MOVE_ERR_OUT_OF_BOARD;
    }

    const Cell* start = &board->cells[cell_index(from_row, from_col)];
    const Cell* dest = &board->cells[cell_index(to_row, to_col)];

    if (start->piece.party == PARTY_NONE) {
        return MOVE_ERR_NO_PIECE;
    }
    if (start->piece.party != player) {
        return MOVE_ERR_NOT_YOUR_PIECE;
    }
    if (from_row == to_row && from_col == to_col) {
        return MOVE_ERR_SAME_SQUARE;
    }
    if (from_row != to_row && from_col != to_col) {
        return MOVE_ERR_NOT_STRAIGHT;
    }
    if (dest->piece.party != PARTY_NONE) {
        return MOVE_ERR_DESTINATION_OCCUPIED;
    }
    if (dest->type == Castle && start->piece.rank != RANK_K) {
        return MOVE_ERR_CASTLE_RESERVED;
    }
    if (player != PARTY_A && player != PARTY_D) {
        return MOVE_ERR_BAD_ARGUMENT; 
    }

    /* Walk from the start toward the destination, one square at a time.
     * Every step is -1, 0 or +1, so the walk cannot jump out of the board. */
    int row_step = sign(to_row - from_row);
    int col_step = sign(to_col - from_col);
    int row = from_row + row_step;
    int col = from_col + col_step;

    while (row != to_row || col != to_col) {
        const Cell* between = &board->cells[cell_index(row, col)];
        if (between->piece.party != PARTY_NONE || between->type == Castle) {
            return MOVE_ERR_PATH_BLOCKED;
        }
        row += row_step;
        col += col_step;
    }
    return MOVE_OK;
}

MoveResult check_move(const Board* board, const Position* from,
    const Position* to, Party player)
{
    if (board == NULL || from == NULL || to == NULL) {
        return MOVE_ERR_BAD_ARGUMENT;
    }
    return check_move_rc(board, row_of(from), col_of(from),
        row_of(to), col_of(to), player);
}

bool is_move_valid(const Board* board, const Position* from,
    const Position* to, Party player)
{
    return check_move(board, from, to, player) == MOVE_OK;
}


/* ================== captures ================== */

/* Can the square (row, col) be the far end of a sandwich for 'mover'?
 * Yes if it holds a friendly piece, or if it is the empty castle.
 * Off the board: no (board edges are not hostile). */
static bool is_sandwich_partner(const Board* board, int row, int col, Party mover)
{
    if (!in_bounds(row, col)) {
        return false;
    }

    const Cell* cell = &board->cells[cell_index(row, col)];

    if (cell->piece.party == PARTY_NONE) {
        return cell->type == Castle;
    }

    return cell->piece.party == mover;
}

/* Sandwich captures around the piece that has just moved to (row, col). */
static int capture_sandwiches(Board* board, int row, int col, Party mover)
{
    int captured = 0;

    for (int d = 0; d < DIRECTION_COUNT; d++) {
        int victim_row = row + DIRECTIONS[d][0];
        int victim_col = col + DIRECTIONS[d][1];
        int far_row = victim_row + DIRECTIONS[d][0];
        int far_col = victim_col + DIRECTIONS[d][1];

        if (!in_bounds(victim_row, victim_col)) {
            continue;
        }

        Cell* victim = &board->cells[cell_index(victim_row, victim_col)];

        if (victim->piece.party != opponent_of(mover)) {
            continue;
        }

        if (is_sandwich_partner(board, far_row, far_col, mover)) {
            remove_piece(victim);
            captured++;
        }
    }
    return captured;
}

/* Collects the group of 'side' that contains the piece at index 'start',
 * using a stack instead of recursion. Every piece is pushed at most once
 * (visited[] is set when it is pushed), so the stack never exceeds BOARD_SIZE. */
static void explore_group(const Board* board, int start, Party side,
    bool visited[BOARD_SIZE], Group* group)
{
    int stack[BOARD_SIZE];
    int top = 0;

    group->size = 0;
    group->touches_edge = false;
    group->can_move = false;

    stack[top++] = start;
    visited[start] = true;

    while (top > 0) {
        int index = stack[--top];
        const Cell* cell = &board->cells[index];
        int row = index / COLUMN_COUNT;
        int col = index % COLUMN_COUNT;

        group->cells[group->size++] = index;
        if (cell->type == Edge) {
            group->touches_edge = true;
        }

        for (int d = 0; d < DIRECTION_COUNT; d++) {
            int next_row = row + DIRECTIONS[d][0];
            int next_col = col + DIRECTIONS[d][1];

            if (!in_bounds(next_row, next_col)) {
                continue;
            }

            int next = cell_index(next_row, next_col);

            if (board->cells[next].piece.party == side) {
                /* same side and touching: part of the group */
                if (!visited[next]) {
                    visited[next] = true;
                    stack[top++] = next;
                }
            }
            else if (check_move_rc(board, row, col, next_row, next_col, side) == MOVE_OK) {
                /* A rook-like piece can move only if it can step on a
                 * neighbouring square, so testing the 4 neighbours is the same as
                 * testing every destination (as long as nobody crosses the castle). */
                group->can_move = true;
            }
        }
    }
}

/* Encirclement: only the groups touching the piece that has just moved
 * can have become enclosed by this move. */
static int capture_encircled_groups(Board* board, int row, int col, Party mover)
{
    Party side = opponent_of(mover);
    bool visited[BOARD_SIZE] = { false };
    Group group;
    int captured = 0;

    for (int d = 0; d < DIRECTION_COUNT; d++) {
        int next_row = row + DIRECTIONS[d][0];
        int next_col = col + DIRECTIONS[d][1];

        if (!in_bounds(next_row, next_col)) {
            continue;
        }

        int start = cell_index(next_row, next_col);

        if (board->cells[start].piece.party != side || visited[start]) {
            continue;
        }

        explore_group(board, start, side, visited, &group);

        if (group.size >= 2 && !group.touches_edge && !group.can_move) {
            for (int i = 0; i < group.size; i++) {
                remove_piece(&board->cells[group.cells[i]]);
            }
            captured += group.size;
        }
    }
    return captured;
}

int check_capture(Board* board, const Position* moved_to)
{
    if (board == NULL || moved_to == NULL) {
        return 0;
    }

    int row = row_of(moved_to);
    int col = col_of(moved_to);

    if (!in_bounds(row, col)) {
        return 0;
    }

    Party mover = board->cells[cell_index(row, col)].piece.party;

    if (mover == PARTY_NONE) {
        return 0;
    }

    int captured = 0;

    captured += capture_encircled_groups(board, row, col, mover);
    captured += capture_sandwiches(board, row, col, mover);
    return captured;
}


/* ================== move and end of game ================== */

void apply_move(Board* board, const Position* from, const Position* to)
{
    if (board == NULL || from == NULL || to == NULL)
        return;

    int from_row = row_of(from);
    int from_col = col_of(from);
    int to_row = row_of(to);
    int to_col = col_of(to);

    if (!in_bounds(from_row, from_col) || !in_bounds(to_row, to_col))
        return;

    Cell* start = &board->cells[cell_index(from_row, from_col)];

    if (check_move_rc(board, from_row, from_col,
        to_row, to_col, start->piece.party) != MOVE_OK)
        return;

    Cell* dest = &board->cells[cell_index(to_row, to_col)];

    dest->piece = start->piece;
    remove_piece(start);
}

int is_game_over(const Board* board)
{
    /* 0: not over, 1: attackers win, 2: defenders win, 3: draw */
    if (board == NULL) {
        return 0;
    }

    bool king_found = false;
    bool king_on_edge = false;
    int defenders = 0, attackers = 0;              /* defender pawns, the king is not counted */

    for (int i = 0; i < BOARD_SIZE; i++) {
        const Cell* cell = &board->cells[i];

        if (cell->piece.party == PARTY_NONE) {
            continue;
        }
        if (cell->piece.rank == RANK_K) {
            king_found = true;
            if (cell->type == Edge) {
                king_on_edge = true;
            }
        }
        else if (cell->piece.party == PARTY_D) {
            defenders++;
        }
        else if (cell->piece.party == PARTY_A) {
            attackers++;
        }
    }

    if (!king_found) {
        return 1;
    }
    if (king_on_edge) {
        return 2;
    }
    if (defenders == 0) {
        return 3;
    }
	if (attackers == 0) {
		return 2;
	}
    return 0;
}

#include <stdbool.h>
#include "board.h"

 /* Result of a move check. MOVE_OK means the move is legal;
  * every other value says which rule the move breaks.
  * The checks are done in this order, the first failure is returned. */
typedef enum {
    MOVE_OK = 0,
    MOVE_ERR_BAD_ARGUMENT,        /* a NULL pointer was passed                  */
    MOVE_ERR_OUT_OF_BOARD,        /* start or destination is outside A-K / 1-11 */
    MOVE_ERR_NO_PIECE,            /* the start square is empty                  */
    MOVE_ERR_NOT_YOUR_PIECE,      /* the piece belongs to the other player      */
    MOVE_ERR_SAME_SQUARE,         /* start and destination are the same square  */
    MOVE_ERR_NOT_STRAIGHT,        /* not along a row or a column                */
    MOVE_ERR_DESTINATION_OCCUPIED,/* another piece is on the destination        */
    MOVE_ERR_CASTLE_RESERVED,     /* only the king may stop on the castle       */
    MOVE_ERR_PATH_BLOCKED         /* a piece, or the castle, is in the way      */
} MoveResult;

/* Says why a move is refused (text shown to the player). */
const char* move_error_message(MoveResult result);

/* Checks a move for 'player'. Returns MOVE_OK or the first rule broken. */
MoveResult check_move(const Board* board, const Position* from,
    const Position* to, Party player);

/* Same check, as a yes/no answer. */
bool is_move_valid(const Board* board, const Position* from,
    const Position* to, Party player);

/* Applies every capture caused by the piece that has just moved to 'moved_to'.
 * Order: encirclement, then sandwich, then king capture.
 * Returns the number of pieces removed from the board. */
int check_capture(Board* board, const Position* moved_to);

/* Moves the piece. Does nothing if the move is not possible
 * (call check_move() first). */
void apply_move(Board* board, const Position* from, const Position* to);

/* 0: not over, 1: attackers win (king captured), 2: defenders win (king on an
 * edge), 3: draw (no defender left besides the king). */
int is_game_over(const Board* board);

#endif

#include "ui.h"
#include <stdio.h>

#define RESET       "\x1b[0m"
#define BORDER      "\x1b[90m"
#define DEFENDER    "\x1b[94;1m"
#define ATTACKER    "\x1b[91;1m"
#define KING        "\x1b[96;1m"
#define HIGHLIGHT   "\x1b[43;1m"
#define CASTLE      "\x1b[33;1m"

void render_board(const Board* board, const Position* last_move)
{
    if (board == NULL)
        return;

    printf("\n");

    for (int row = ROW_COUNT - 1; row >= 0; row--) {
        printf(" %2d  ", row + 1);

        for (int col = 0; col < COLUMN_COUNT; col++) {
            const Cell* cell = &board->cells[row * COLUMN_COUNT + col];

            int highlighted = last_move != NULL &&
                last_move->row == row + 1 &&
                last_move->column == 'A' + col;

            char symbol = ' ';
            const char* foreground = RESET;

            if (cell->piece.party == PARTY_A && cell->piece.rank == RANK_P) {
                symbol = 'a';
                foreground = ATTACKER;
            }
            else if (cell->piece.party == PARTY_D && cell->piece.rank == RANK_P) {
                symbol = 'd';
                foreground = DEFENDER;
            }
            else if (cell->piece.party == PARTY_D && cell->piece.rank == RANK_K) {
                symbol = 'k';
                foreground = KING;
            }
            else if (cell->piece.party == PARTY_NONE && cell->type == Castle) {
                symbol = '+';
                foreground = CASTLE;
            }

            if (highlighted)
                printf("%s", HIGHLIGHT);

            printf("%s %c %s", foreground, symbol, RESET);

            if (col < COLUMN_COUNT - 1)
                printf("%s|%s", BORDER, RESET);
        }

        printf("\n");

        if (row > 0) {
            printf("     ");

            for (int col = 0; col < COLUMN_COUNT; col++) {
                printf("%s---%s", BORDER, RESET);

                if (col < COLUMN_COUNT - 1)
                    printf("%s+%s", BORDER, RESET);
            }

            printf("\n");
        }
    }

    printf("     ");

    for (int col = 0; col < COLUMN_COUNT; col++)
        printf(" %c  ", 'A' + col);

    printf("\n\n");
}

/* ---------- helpers: build positions on an empty board ---------- */

static Position at(char column, int row)
{
    Position pos;
    pos.column = column;
    pos.row = row;
    return pos;
}

static Cell* cell(Board* board, char column, int row)
{
    return &board->cells[(row - 1) * COLUMN_COUNT + (column - 'A')];
}

static void put(Board* board, char column, int row, Party party, Rank rank)
{
    cell(board, column, row)->piece.party = party;
    cell(board, column, row)->piece.rank = rank;
    cell(board, column, row)->piece.id = 1;
}

static void put_attacker(Board* board, char column, int row) { put(board, column, row, PARTY_A, RANK_P); }
static void put_defender(Board* board, char column, int row) { put(board, column, row, PARTY_D, RANK_P); }
static void put_king(Board* board, char column, int row)     { put(board, column, row, PARTY_D, RANK_K); }

static bool is_empty(Board* board, char column, int row)
{
    return cell(board, column, row)->piece.party == PARTY_NONE;
}

static MoveResult move(const Board* board, char c1, int r1, char c2, int r2, Party player)
{
    Position from = at(c1, r1);
    Position to = at(c2, r2);
    return check_move(board, &from, &to, player);
}

static int capture(Board* board, char column, int row)
{
    Position pos = at(column, row);
    return check_capture(board, &pos);
}

/* ---------- sandwich ---------- */

static void test_sandwich(void)
{
    Board board = board_make();

    /* basic capture: attacker arrives on C5, defender D5, attacker E5 */
    put_attacker(&board, 'E', 5);
    put_defender(&board, 'D', 5);
    put_attacker(&board, 'C', 5);
    assert(capture(&board, 'C', 5) == 1);
    assert(is_empty(&board, 'D', 5));
    assert(!is_empty(&board, 'C', 5));

    /* far square empty: no capture */
    board = board_make();
    put_defender(&board, 'D', 5);
    put_attacker(&board, 'C', 5);
    assert(capture(&board, 'C', 5) == 0);
    assert(!is_empty(&board, 'D', 5));

    /* far square off the board: edges are not hostile */
    board = board_make();
    put_defender(&board, 'A', 5);
    put_attacker(&board, 'B', 5);
    assert(capture(&board, 'B', 5) == 0);
    assert(!is_empty(&board, 'A', 5));

    /* empty castle is hostile */
    board = board_make();
    put_defender(&board, 'F', 7);
    put_attacker(&board, 'F', 8);
    assert(capture(&board, 'F', 8) == 1);
    assert(is_empty(&board, 'F', 7));

    /* castle occupied by the king is not hostile to attackers */
    board = board_make();
    put_king(&board, 'F', 6);
    put_defender(&board, 'F', 7);
    put_attacker(&board, 'F', 8);
    assert(capture(&board, 'F', 8) == 0);
    assert(!is_empty(&board, 'F', 7));
}

static void test_sandwich_exceptions(void)

    put_defender(&board, 'C', 3);

    put_attacker(&board, 'E', 3);

    assert(capture(&board, 'D', 4) == 0);
    assert(!is_empty(&board, 'C', 3));
    assert(!is_empty(&board, 'D', 3));

    /* L-shape of three */
    board = board_make();

    board = board_make();

static void test_encirclement_exceptions(void)
{
    Board board = board_make();

    /* a group touching the edge is never captured */
    put_defender(&board, 'A', 3);
    put_defender(&board, 'B', 3);
    put_attacker(&board, 'A', 2);
    put_attacker(&board, 'A', 4);
    put_attacker(&board, 'B', 2);
    put_attacker(&board, 'B', 4);
    put_attacker(&board, 'C', 3);
    assert(capture(&board, 'C', 3) == 0);
    assert(!is_empty(&board, 'A', 3) && !is_empty(&board, 'B', 3));

    /* a group containing the king can be captured by encirclement */
    board = board_make();
    put_king(&board, 'C', 3);
    put_defender(&board, 'D', 3);
    put_attacker(&board, 'B', 3);
    put_attacker(&board, 'C', 2);
    put_attacker(&board, 'C', 4);
    put_attacker(&board, 'D', 2);
    put_attacker(&board, 'D', 4);
    put_attacker(&board, 'E', 3);
    assert(capture(&board, 'E', 3) == 2);
    assert(is_empty(&board, 'C', 3) && is_empty(&board, 'D', 3));

    /* the mover's own enclosed group stays: only the mover captures */
    board = board_make();
    put_attacker(&board, 'C', 3);
    put_attacker(&board, 'D', 3);
    put_defender(&board, 'B', 3);
    put_defender(&board, 'E', 3);
    put_defender(&board, 'C', 2);
    put_defender(&board, 'D', 2);
    put_defender(&board, 'C', 4);
    put_defender(&board, 'D', 4);
    put_attacker(&board, 'I', 9);
    assert(capture(&board, 'I', 9) == 0);
    assert(!is_empty(&board, 'C', 3) && !is_empty(&board, 'D', 3));

    /* defenders can encircle an attacker group too */
    put_defender(&board, 'D', 4);
    assert(capture(&board, 'D', 4) == 2);
    assert(is_empty(&board, 'C', 3) && is_empty(&board, 'D', 3));
}

static void test_apply_and_outcome(void)
{
    Board board = board_make();
    board_init(&board);
    assert(is_game_over(&board) == 0);                 /* start position */

    Position from = at('F', 2);
    Position to = at('F', 3);
    assert(check_move(&board, &from, &to, PARTY_A) == MOVE_OK);
    apply_move(&board, &from, &to);
    assert(is_empty(&board, 'F', 2) && !is_empty(&board, 'F', 3));

    board = board_make();                              /* no king */
    put_attacker(&board, 'E', 5);
    assert(is_game_over(&board) == 1);

    board = board_make();                              /* king on an edge */
    put_king(&board, 'A', 6);
    put_defender(&board, 'C', 3);
    assert(is_game_over(&board) == 2);

    board = board_make();                              /* only the king left */
    put_king(&board, 'E', 5);
    put_attacker(&board, 'C', 3);
    assert(is_game_over(&board) == 3);

    board = board_make();                              /* game goes on */
    put_king(&board, 'E', 5);
    put_defender(&board, 'C', 3);
    put_attacker(&board, 'I', 9);
    assert(is_game_over(&board) == 0);
}

#include <assert.h>
#include <stdio.h>

#include "rules.h"

#define CELL(b, col, row) \
    (&(b).cells[((row) - 1) * COLUMN_COUNT + ((col) - 'A')])

int main(void)
{
    Board board = board_make();

    Position from = { 2, 'B' };
    Position to = { 5, 'B' };

    // Place an attacking pawn at B2
    CELL(board, 'B', 2)->piece = (Piece){ PARTY_A, RANK_P, 101 };
    assert(CELL(board, 'B', 2)->piece.party != PARTY_NONE);

    // Valid straight-line movement
    assert(is_move_valid(&board, &from, &to, PARTY_A));

    // Wrong player's turn
    assert(!is_move_valid(&board, &from, &to, PARTY_D));

    // Diagonal movement
    Position diagonal = { 5, 'C' };
    assert(!is_move_valid(&board, &from, &diagonal, PARTY_A));

    // Blocked path
    CELL(board, 'B', 4)->piece.party = PARTY_D;
    assert(!is_move_valid(&board, &from, &to, PARTY_A));

    // Clear path again
    CELL(board, 'B', 4)->piece.party = PARTY_NONE;
    assert(is_move_valid(&board, &from, &to, PARTY_A));

    // Apply movement
    apply_move(&board, &from, &to);

    assert(CELL(board, 'B', 2)->piece.party == PARTY_NONE);
    assert(CELL(board, 'B', 5)->piece.party != PARTY_NONE);
    assert(CELL(board, 'B', 5)->piece.id == 101);

    printf("test_rules: OK\n");

    return 0;
}
